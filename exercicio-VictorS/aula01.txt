1. Dado const nums = [1, 2, 3, 4], escreva uma linha que produza [2, 4, 6, 8].

const resultado = nums.map((n) => n * 2);

2. Na mesma lista, escreva uma linha que produza só os números pares.

const pares = nums.filter((n) => n % 2 === 0);

3. Explique em uma frase, sem código, a diferença entre map e filter.
O map transforma os itens da lista, enquanto o filter seleciona só os itens que passam em uma condição.

4. Dado const p = { titulo: "Caneca", preco: 25 }, desestruture titulo e preco em uma linha.

const { titulo, preco } = p;

5. Escreva uma função de seta chamada ehCaro que recebe um número e devolve verdadeiro se for maior que 100.

const ehCaro = (n) => n > 100;

6. Dado const cores = ["azul", "verde"], crie cores2 com "vermelho"no fim, sem alterar cores.

const cores2 = [...cores, "vermelho"];

7. Dado o objeto p da questão 4, crie pEmPromocao com preço 20, sem alterar p.

const pEmPromocao = { ...p, preco: 20 };

8. Dada a lista de produtos abaixo, escreva uma linha que devolva só os nomes dos produtos em estoque.

const nomes = produtos.filter((p) => p.estoque > 0).map((p) => p.nome);

10. Qual a diferença entre import Botao from "./Botao.js" e import { Botao } from "./Botao.js"?
import Botao from "./Botao.js" é usado quando o arquivo tem export default. Já import { Botao } from "./Botao.js" é usado quando foi feito um export normal com o nome Botao.

11. Explique por que lista.push(novo) é um problema dentro de um componente React.
Porque o push altera a lista original, e no React o certo é criar uma nova lista para ele perceber a mudança e atualizar a tela.
